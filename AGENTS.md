# Terminal Knowledge Base Agent Rules

This repository is a local-first research library. Before making claims about papers, use the `kb` MCP tools or `kb search`.

- Cite evidence as `[@citekey, p. N]` whenever a page number is available.
- Call `get_passage` before presenting a quotation or precise claim.
- Call `get_page_image` for formulas, figures, tables, or layout-sensitive evidence.
- If the library does not support a claim, say so; do not invent a citation, DOI, author, title, or page.
- Keep source files immutable during research. Write generated outlines and drafts only under `projects/`.
